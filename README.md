# О проекте

Простой сервер для веб-чата в реальном времени на Node.js + Express + Socket.IO.

## Возможности

- Подключение пользователей через WebSocket
- Динамическое создание комнат
- Передача и широковещательная рассылка сообщений
- Автоматическое уведомление о подключении/отключении пользователей

## Технологии

- Backend: Node.js, Express, Socket.IO
- Инструменты: npm
- Реальное время: Socket.IO для обмена сообщениями между пользователями

## Установка и запуск

- git clone https://github.com/steel-mountain/chat-server.git
- cd chat-server
- npm install
- npm run dev

Сервер будет запущен на http://localhost:5000 по умолчанию.
Для работы необходимо запустить фронтенд (chat-client).

## Использование

- Клиент подключается к серверу через Socket.IO
- Пользователь вводит название комнаты и имя
- Сервер создаёт комнату автоматически, если она ещё не существует
- Все участники комнаты обмениваются сообщениями в реальном времени
